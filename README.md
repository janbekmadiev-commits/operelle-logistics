# OPERELLE Logistics

Демо логистической платформы OPERELLE: автоперевозки, авиаперевозки, ЖД и морские перевозки.
У каждого направления сайт клиента и панель управления, всем управляет единая панель OPERELLE.

Открыть: https://janbekmadiev-commits.github.io/operelle-logistics/

- `index.html`: стартовая страница с кнопками «Поделиться» и QR-кодами (адрес берётся от места, где лежит сайт)
- `all4.html`: единая панель OPERELLE на четыре направления
- `p-auto-*.html`, `p-air-*.html`, `p-rail-*.html`, `p-sea-*.html`: сайт и панель каждого направления
- `help.html`: инструкция
- `rates.json`: курсы Национального Банка Казахстана, обновляются каждый час заданием `.github/workflows/rates.yml` (программа `tools/nbk_rates.py`)
- `materials/`: все материалы по отдельности и единые файлы

Все данные демонстрационные и хранятся в браузере устройства.
